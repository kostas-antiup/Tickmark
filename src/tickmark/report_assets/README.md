# Report assets

Embedded into every `report.html` so the report is a single self-contained file.

- `aai-labs-wordmark.svg` — AAI Labs wordmark from the AAI Labs Design System brand kit
  (`assets/logo/main-blue.svg`), with `fill="currentColor"` so CSS sets its colour.
- `dm-sans.woff`, `ibm-plex-sans.woff`, `ibm-plex-mono-500.woff`, `ibm-plex-mono-600.woff` —
  DM Sans and IBM Plex fonts from the same brand kit, subset to Latin text characters and
  converted to WOFF with fontTools (`pyftsubset`). Both families are licensed under the
  SIL Open Font License 1.1 (https://openfontlicense.org).

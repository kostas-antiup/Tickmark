# Brand assets

Tickmark is an AAI Labs benchmark and uses the AAI Labs design system: one electric-blue
accent, near-black ink, DM Sans for the wordmark and display type, IBM Plex Sans for text
and IBM Plex Mono for labels.

| File | Use |
|---|---|
| `logo/tickmark-logo-{blue,black,white}.svg` | Primary lockup: dot-matrix tick, divider, wordmark. Blue or black on light backgrounds, white on blue or dark. |
| `logo/tickmark-mark-{blue,black,white}.svg` | The tick on its own, square, for small spaces. |
| `logo/tickmark-icon.png` | 512 px avatar: white tick on blue. |
| `logo/aai-labs-logo-{blue,black,white}.svg` | AAI Labs lockup for "created by" credits. |
| `banner.png` | README header, 2560 x 880. |
| `social-preview.png` | Repository social preview, 1280 x 640 (Settings > Social preview). |
| `how-it-works.png` | README figure. |

The tick is drawn on the same dot grid as the AAI Labs mark (20.9-unit pitch, 15.47-unit
dots) and the lockup repeats the AAI Labs proportions: the mark spans the cap height, then a
divider, then the wordmark in DM Sans Light. All text in the SVGs is converted to outlines,
so the files render the same without the fonts installed.

| Token | Value |
|---|---|
| Blue | `#0000F0` |
| Ink | `#0A0A0A` |
| Lilac tint | `#F0F0FF` |
| Hairline | `#E6E7EA` |
| Subtle background | `#F8F9FA` |
